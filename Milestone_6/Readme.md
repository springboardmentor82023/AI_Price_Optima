🚀 Milestone 6 – Deployment & Dashboard

The objective of this milestone is to deploy the dynamic pricing system using a Streamlit-based interactive dashboard.
The application integrates the trained machine learning model, pricing logic, and user input interface for real-time price recommendations.
It displays key outputs such as recommended price, expected revenue, and KPI visualizations including revenue comparison and demand trends.
The dashboard also includes a comparison of static, rule-based, and ML-based pricing to demonstrate revenue improvement.
This final application provides a user-friendly interface that simulates real-world business pricing decisions.
