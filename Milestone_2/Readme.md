⚙️ Milestone 2 – Data Ingestion Pipeline

The objective of this milestone is to build a Python-based data ingestion pipeline that reads raw sales data, performs validation and cleaning, and stores it in a structured format.
The pipeline processes datasets from the raw folder, handles missing values, removes duplicates, and ensures correct data types.
Cleaned data is stored in the processed folder, and a date-wise copy is saved in the daily_ingest folder to simulate daily data updates.
The ingestion script (ingest.py) runs successfully multiple times without errors and prints logs for each step of execution.
This pipeline simulates real-world business data processing and forms the foundation for further analysis and model development.
