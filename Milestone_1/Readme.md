# 📊 Milestone 1 – Dataset Overview

The dataset used for this project is the **Online Retail dataset from Kaggle**, which contains transactional data of an e-commerce store.
It includes features such as InvoiceNo, StockCode, Description, Quantity, InvoiceDate, UnitPrice, CustomerID, and Country.
This dataset helps analyze pricing behavior, customer demand, and sales patterns over time.
It contains more than 1000 records with time-based data, making it suitable for EDA and machine learning.
Overall, it provides a strong foundation for building a dynamic pricing and revenue optimization system.
