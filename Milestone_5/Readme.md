🤖 Milestone 5 – Advanced Model Development

The objective of this milestone is to develop machine learning models (XGBoost and LightGBM) to predict demand and support dynamic pricing decisions.
The models were trained using processed data with features such as price, inventory, and time-based variables to learn demand patterns.
Model performance was evaluated using metrics like MAE, RMSE, and R² score to ensure accuracy.
Backtesting was performed using historical data to simulate pricing decisions and calculate expected revenue.
Revenue comparison across static, rule-based, and ML-based pricing showed that machine learning improves pricing effectiveness and revenue.
